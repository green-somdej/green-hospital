# Green Hospital

เว็บไซต์โรงพยาบาลสีเขียว โรงพยาบาลสมเด็จพระบรมราชเทวี ณ ศรีราชา
ศูนย์รวมเอกสาร ลิงก์ และกิจกรรมของทั้ง 7 หมวด

หน้าเว็บ (บน GitHub Pages) ดึงข้อมูลจาก Google Sheet เดิมผ่าน Google Apps Script
เมื่อแก้ไขข้อมูลใน Sheet หน้าเว็บจะอัปเดตตามภายในประมาณ 1 นาที ไม่ต้องแก้โค้ด

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด ได้แก่ หน้าปก หน้าหมวด และหน้ากิจกรรม |
| `config.js` | ใส่ลิงก์ Apps Script (แก้แค่ไฟล์นี้) |
| `apps-script/Code.gs` | โค้ดฝั่ง Google Apps Script ที่ส่งข้อมูลจาก Sheet ให้หน้าเว็บ |

## ขั้นที่ 1: อัปเดต Apps Script

1. เปิด Google Sheet แล้วไปที่ **ส่วนขยาย → Apps Script**
2. เปิดไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจาก `apps-script/Code.gs` แทน กดบันทึก
   (ไฟล์ `Index` เดิมใน Apps Script เก็บไว้ได้ ลิงก์เว็บเดิมจะยังใช้งานได้)
3. กด **Deploy → Manage deployments** → แก้ไข (ไอคอนดินสอ) → **Version: New version**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 2: ใส่ลิงก์ใน `config.js`

```js
window.GH_CONFIG = {
  apiUrl: "https://script.google.com/macros/s/xxxxxxxx/exec"
};
```

## ขั้นที่ 3: ขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub (เช่น `green-hospital`) แบบ **Public**
2. กด **Add file → Upload files** แล้วลากไฟล์ `index.html`, `config.js`, `README.md` และโฟลเดอร์ `apps-script` ขึ้นไป แล้วกด Commit
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/green-hospital/`

## ความปลอดภัย

Apps Script ทำงานด้วยสิทธิ์ของเจ้าของ จึงตั้งให้ส่งได้เฉพาะไฟล์ที่ใส่ลิงก์ไว้ใน Sheet
(หรือไฟล์ที่อยู่ในโฟลเดอร์ที่ใส่ลิงก์ไว้) ไฟล์อื่นใน Drive จะเปิดผ่านเว็บไม่ได้
เมื่อเพิ่มไฟล์ใหม่ใน Sheet อาจต้องรอประมาณ 2 นาทีจึงจะเปิดได้ ถ้าต้องการให้ใช้ได้ทันทีให้รันฟังก์ชัน `clearCache`

ห้ามใส่ลิงก์โฟลเดอร์ใหญ่ (เช่นโฟลเดอร์รวมทั้งหน่วยงาน) ลงใน Sheet เพราะไฟล์ทุกไฟล์ในโฟลเดอร์นั้นจะเปิดผ่านเว็บได้

## วิธีเพิ่มข้อมูลใน Sheet

| ชีต | คอลัมน์ |
|---|---|
| หมวด | A=เลขหมวด B=ชื่อ C=คำอธิบาย D=ลิงก์รูป E=สี (ไม่บังคับ) F=ลิงก์เอกสาร |
| ลิงก์ | A=เลขหมวด B=ชื่อลิงก์ C=URL |
| ภาพรวม | A=เลขหมวด B=ชื่อที่แสดง C=ลิงก์ฝัง/โค้ด iframe/ไฟล์ HTML ใน Drive D=ความสูง px E=รีเฟรชทุกกี่นาที F=แสดงผล |
| กิจกรรม | A=วันที่ B=หมวด (เช่น "หมวด 3") C=ชื่อ D=รายละเอียด E=URL F=รูป G=แสดงผล |
| สไลด์ | A=ลำดับ B=ลิงก์รูปหรือโฟลเดอร์ C=หัวข้อ D=คำบรรยาย E=ลิงก์ F=แสดงผล |
| ประชาสัมพันธ์ | A=ข้อความ B=แสดงผล |
| การตั้งค่า | A=คีย์ (โลโก้ / หัวเว็บ / มาสคอต) B=ลิงก์รูป |

- ถ้าใส่ "หัวเว็บ" รูปนั้นจะแสดงแทนภาพประกอบบนหน้าปก
- ถ้าใส่ "มาสคอต" รูปนั้นจะแสดงในส่วน "เริ่มใช้งานง่าย ๆ"
- ถ้าไม่มีชีตสไลด์ หน้าเว็บจะใช้รูปจากชีตกิจกรรมแทน
